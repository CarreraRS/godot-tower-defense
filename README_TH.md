# Haupttür — ฉากที่ 1 (Preview)

เกม 3D Tower Defense: กองทัพสมัยใหม่บุกออกมาจากประตูมิติ **Haupttür** ผู้เล่นเป็นแม่ทัพของอาณาจักรที่ต้องวางยูนิตป้องกันเมือง

## วิธีเปิดเล่น
1. เปิดโปรเจกต์ใน Godot 4.7 (รอให้ editor import ไฟล์ใหม่สักครู่)
2. กด **F5** (Run Project) เกมจะเริ่มที่เมนูหลัก `td/scenes/main_menu.tscn`
3. ถ้าจะเข้าด่านโดยตรง ให้เปิด `td/scenes/level_01.tscn` แล้วกด **F6**

> ฉากเดิมของโปรเจกต์ (`scenes/main.tscn`) ยังอยู่ครบ ไม่ได้แก้ไข

## การควบคุม
| ปุ่ม | การทำงาน |
|---|---|
| คลิกปุ่มยูนิตด้านล่าง หรือกด 1–7 | เลือกยูนิตที่จะวาง |
| คลิกซ้ายบนช่องว่าง | วางยูนิต (กด Shift ค้างเพื่อวางต่อเนื่อง) |
| คลิกซ้ายบนยูนิต | เลือกยูนิต แล้วกด U = อัปเกรด, X = ขาย |
| คลิกขวา / Esc | ยกเลิก |
| Space | เริ่ม Phase ถัดไป |
| M หรือปุ่ม "เพลง" | เปิด/ปิดเพลงประกอบ |
| WASD / ลูกศร, ล้อเมาส์, Q/E, คลิกกลางลาก | เลื่อนกล้อง, ซูม, หมุน, ลากกล้อง |

## ระบบที่มี
- ทรัพยากร (ทอง): เริ่ม 300 ได้เพิ่มจากการฆ่าศัตรูและโบนัสจบ Phase
- 6 Phase (Phase สุดท้ายเป็น **Boss Phase** — เครื่องบินทิ้งระเบิด)
- ศัตรูภาคพื้นเดินตามถนน ส่วนศัตรูอากาศบินเป็นเส้นตรงข้ามแผนที่ ยูนิตบางชนิดยิงอากาศยานไม่ได้
- เกราะ: รถถังลดดาเมจจากการโจมตีทีละน้อย ๆ ต้องใช้ Ballista (เจาะเกราะ) หรือดาเมจแรง ๆ
- อัปเกรดยูนิตได้ 3 เลเวล และขายคืนได้ 70%
- กำแพงเมือง 20 แต้ม ถ้าเหลือ 0 = ภารกิจล้มเหลว, ชนะ Boss Phase = ภารกิจสำเร็จ
- ปุ่มความเร็ว x2 และหยุดชั่วคราว

## เพลงประกอบ (BGM)
อยู่ใน `td/audio/` เป็นเพลงที่แต่งและสังเคราะห์ขึ้นใหม่ทั้งหมด (ไม่ติดลิขสิทธิ์)
| ไฟล์ | ใช้ตอน |
|---|---|
| `bgm_menu.ogg` | เมนูหลัก |
| `bgm_battle.ogg` | ระหว่างด่าน |
| `bgm_boss.ogg` | Boss Phase |
| `stinger_victory.ogg` / `stinger_defeat.ogg` | ชนะ / แพ้ |

อยากเปลี่ยนเพลง: เอาไฟล์ .ogg ใหม่มาวางทับชื่อเดิม หรือแก้ path ใน `TRACKS` ของ `td/scripts/music.gd` ปรับความดังที่ `VOLUME_DB`

## ยูนิต
**ฝ่ายอาณาจักร (7):** Archer, Knight, Mage (ทำให้ช้า), Wizard (ลูกไฟกระจาย), Ballista (เจาะเกราะ), Catapult (ยิงไกล กระจาย), Dragon
**ฝ่ายประตูมิติ (6):** Soldier, Humvee, Tank, Helicopter, Jet, Bomber (บอส)

## โครงสร้างไฟล์ (`td/`)
| โฟลเดอร์ | เนื้อหา |
|---|---|
| `scenes/` | `main_menu.tscn`, `level_01.tscn` |
| `scripts/` | `level.gd` (แผนที่/ทอง/Phase/การวาง), `enemy.gd`, `defender.gd`, `projectile.gd`, `hud.gd`, `waves_level01.gd` |
| `data/defenders/`, `data/enemies/` | ค่าพลังของแต่ละยูนิต (.tres) แก้ใน Inspector ได้เลย |
| `models/` | โมเดล low-poly ของทุกยูนิต + ประตูมิติ + ปราสาท |
| `icons/` | ไอคอนยูนิตและภาพพื้นหลังเมนู |

## ปรับแต่งด่าน
- **จำนวนศัตรูแต่ละ Phase:** แก้ใน `td/scripts/waves_level01.gd`
- **ค่าพลัง/ราคา:** เปิดไฟล์ใน `td/data/...` แล้วแก้ใน Inspector
- **รูปเส้นทาง:** แก้ `WAYPOINTS` ใน `td/scripts/level.gd`
- **ทองเริ่มต้น / ชีวิตเมือง:** เลือกโหนด `Level01` ใน `level_01.tscn` แล้วแก้ `start_gold`, `max_lives`

## เปลี่ยนเป็นโมเดลจาก poly.pizza / Sketchfab
1. ดาวน์โหลดเป็น `.glb` แล้ววางใน `assets/`
2. เปิด `td/models/<ชื่อยูนิต>.tscn` ลบ node รูปทรงเดิม แล้วลาก `.glb` เข้ามาแทน
3. ปรับขนาดให้สูงประมาณ 0.6 (ยูนิตทั่วไป) และหันหน้าไปทางแกน **-Z**
4. ให้ node `Muzzle` (จุดยิงกระสุน) ยังอยู่ แล้ววางไว้ที่ปลายอาวุธ
5. ถ้าโมเดลมีแอนิเมชัน ให้ใส่ชื่อใน `attack_anim` / `idle_anim` ของไฟล์ .tres (ดู Wizard เป็นตัวอย่าง)
