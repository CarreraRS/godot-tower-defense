# Haupttür (เฮาพท์-ทือร์) — ฉบับเต็ม

เกม 3D Tower Defense: กองทัพสมัยใหม่บุกออกมาจากประตูมิติ **Haupttür** ผู้เล่นเป็นแม่ทัพของอาณาจักรแฟนตาซีที่ต้องวางกำลังปกป้องเมือง
CP410844 • กลุ่ม 14

## วิธีเปิดเล่น
1. เปิดโปรเจกต์ใน Godot 4.7 (รอ editor import ไฟล์ใหม่สักครู่ — ครั้งแรกอาจมี error เรื่องฟอนต์ ให้ปิดเปิดใหม่ 1 ครั้ง)
2. กด **F5** เกมจะเริ่มที่เมนูหลัก `td/scenes/main_menu.tscn`
3. เวอร์ชันเว็บ: `build/haupttuer_web.zip` (อัปโหลดขึ้น itch.io แบบ HTML ได้ทันที)

## โหมดเกม
| โหมด | รายละเอียด |
|---|---|
| **โหมดเนื้อเรื่อง** | มีคัตซีนเปิดเรื่อง (ประตูมิติผุดขึ้น พระราชาสั่งให้แม่ทัพไปเฝ้าระวัง) → 6 เฟสบนเส้นทางเดียว ระหว่างเฟสมีบทสนทนาสั้น ๆ พร้อมทองสนับสนุนจากพระราชา ยิ่งผ่านเฟส เมืองยิ่งพัง เมื่อบอสปรากฏจะมีคัตซีน "พิธีอัญเชิญผู้กล้า" แล้วให้วางผู้กล้าได้ จบด้วยคัตซีนตอนจบ |
| **โหมดไม่สิ้นสุด** | สุ่มเส้นทางและธีมแมพ (ทุ่งหญ้า / หิมะ / สนธยา) ใหม่ทุกครั้ง ศัตรูแข็งขึ้นเรื่อย ๆ บอสทุก 10 Wave ได้ **เหรียญผู้กล้า** 1 เหรียญทุกครั้งที่ผ่าน Wave ครบ 15 เหรียญอัญเชิญผู้กล้าได้ เก็บสถิติ Wave/คะแนนสูงสุด |

คัตซีน: คลิก/Space เพื่อไปต่อ, Esc เพื่อข้าม (ปิดคัตซีนได้ในเมนู ตั้งค่า) — ตอนชนะประตูมิติระเบิด ตอนแพ้ปราสาทพังทลาย

ตั้งค่า: ระดับเสียง, ความเร็วกล้อง, ความไวเมาส์ ปรับได้ทั้งในเมนูหลักและเมนูหยุดเกม (Esc)

## การควบคุม
| ปุ่ม | การทำงาน |
|---|---|
| คลิกการ์ดด้านล่าง หรือกด 1–7 | เลือกยูนิตที่จะวาง (ชี้เมาส์ค้างดูรายละเอียด + ทักษะ) |
| คลิกซ้ายบนช่องว่าง | วางยูนิต (Shift ค้าง = วางต่อเนื่อง) |
| คลิกยูนิต แล้ว **F** | ใช้ทักษะพิเศษ (เพชรสีทองเหนือหัว = พร้อมใช้) |
| คลิกยูนิต แล้ว U / X | อัปเกรด / ขาย |
| H | วางผู้กล้า (เมื่อปลดล็อกแล้ว) |
| Space | เริ่ม Phase / Wave ถัดไป |
| Esc | ยกเลิก / เมนูหยุดเกม |
| WASD, ล้อเมาส์, Q/E | เลื่อน, ซูม, หมุนกล้อง |

**ฝ่ายประตูมิติ (6) — ชื่อตามที่อาณาจักรเรียก:** นักรบลายพราง (ทหารราบ), รถม้าเหล็กไร้ม้า (ฮัมวี่), ป้อมเหล็กเคลื่อนที่ (รถถัง), นกเหล็กใบพัด (เฮลิคอปเตอร์), เหยี่ยวเหล็กสายฟ้า (เจ็ท), อสูรเหล็กแห่งฟากฟ้า (เครื่องบินทิ้งระเบิด)

**บันทึกหน่วยสอดแนม** (ในทำเนียบกองทัพ): อธิบายศัตรูจากมุมมองคนในโลกแฟนตาซี ศัตรูที่ยังไม่เคยเจอจะเป็น ??? และปลดล็อกเมื่อพบครั้งแรก (แก้บันทึกได้ที่ `lore` / `counter` ในไฟล์ `.tres` ของศัตรู) (บอส — มีเสียงไซเรนเตือนก่อนโผล่ ผู้กล้าที่วางข้างถนนตัดเลือดได้ราวครึ่งหลอดตอนบอสบินผ่าน)

## ระบบศัตรู
- ศัตรูภาคพื้นหยุดหน้าประตูเมืองแล้วโจมตีเป็นจังหวะจนกว่าจะถูกฆ่า
- เฮลิคอปเตอร์/บอสลอยค้างหน้าเมืองยิงจรวด, เจ็ทพุ่งดิ่งชนครั้งเดียว
- ปราสาทยิงสวนศัตรูที่เข้าใกล้ (ไอเดียจากงาน addenemyeffect ของเพื่อนในกลุ่ม)

## โครงสร้างไฟล์ (`td/`)
| ที่อยู่ | เนื้อหา |
|---|---|
| `scenes/` | `main_menu.tscn`, `level_01.tscn` (ใช้ทั้ง 2 โหมด) |
| `scripts/level.gd` | แผนที่, ธีม, สุ่มเส้นทาง, ทอง, Phase/Wave, ปราสาทยิงสวน, ความพังของแมพ |
| `scripts/enemy.gd` | AI ศัตรู: เดิน → ล้อมเมือง / ลอยยิง / ดิ่งชน |
| `scripts/defender.gd` | ยูนิต: เล็งเป้า, โจมตี, ทักษะพิเศษ, บัฟ, ออร่า |
| `scripts/map_decor.gd` | ของตกแต่งแมพ (กำแพง คบไฟ หมู่บ้าน ค่ายศัตรู ไร่นา) + หลุม/ไฟ/ควัน |
| `scripts/waves_level01.gd` | ศัตรูแต่ละเฟส + บทคัตซีนทั้งหมด (INTRO / interlude / HERO_SUMMON / ENDING) แก้บทพูดได้ที่นี่ |
| `scripts/game_session.gd` | โหมดที่เลือก, seed แมพ, สถิติ, ระดับเสียง (บันทึกใน `user://haupttuer.cfg`) |
| `scripts/hud.gd` | UI ในด่าน + ตัวเล่นคัตซีน (แถบดำ กล่องข้อความผุดจากปราสาท) |
| `scripts/main_menu.gd` | เมนูหลัก (ฉากหลังเป็นสนามรบจริงเคลื่อนไหว) |
| `data/defenders/`, `data/enemies/` | ค่าพลัง (.tres) แก้ใน Inspector ได้ |
| `models/` | โมเดล low-poly ของทุกยูนิต (สร้างจากรูปทรงพื้นฐาน) |

## ปรับสมดุล
- ศัตรู/บทพูดแต่ละเฟส: `waves_level01.gd`
- ความอึดศัตรูตามเฟส: `_hp_mult()` ใน `level.gd` (เนื้อเรื่อง +18%/เฟส)
- ค่าทักษะ: ช่อง Ability ในไฟล์ `.tres` ของแต่ละยูนิต (คูลดาวน์ / ระยะเวลา / ตัวคูณ / รัศมี)
- Wave โหมดไม่สิ้นสุด: `_endless_phase()` ใน `level.gd`
- พลังปราสาท: `CASTLE_DAMAGE`, `CASTLE_RELOAD` ใน `level.gd`
- ทองเริ่มต้น/ชีวิตเมือง: `start_gold` (300), `max_lives` (20) ที่โหนด Level01
