# งานที่ยังเหลือ (สำหรับเพื่อนในกลุ่มทำต่อ)

อัปเดตล่าสุด: 14 ต.ค. 2569 — ก่อนนำเสนอวันพฤหัสที่ 15 ต.ค.

## เสร็จแล้ว (รอบล่าสุด)
- [x] เมนูหลักแบบเกมจริง: ฉากหลังเป็นสนามรบ 3D เคลื่อนไหว, โลโก้, เมนูแถบไฮไลต์, แผงวิธีเล่น/ทำเนียบ/ตั้งค่า, เฟดเข้าออก
- [x] เอาระบบ "ศัตรูยิงสกัดจนยูนิตมึน" ออก + ปรับสมดุลใหม่ บอสเคลื่อนที่ช้าลง
- [x] กลับมาใช้ตัวละครสไตล์ low-poly แบบเดิม: อัศวิน, นักธนู (แก้ทิศธนูแล้ว), นักปรุงยา, จอมเวทย์, โกเลม, นักบุญ, มังกร (แบบเดิม)
- [x] ทักษะพิเศษกดใช้ทุกยูนิต (ปุ่ม F) + ผู้กล้าอาเรียน
- [x] เนื้อเรื่อง + คัตซีน: เปิดเรื่อง, บทสนทนาระหว่างเฟส + ทองสนับสนุน, พิธีอัญเชิญผู้กล้าตอนบอสเกิด, ตอนจบ
- [x] โหมดไม่สิ้นสุด: เหรียญผู้กล้า +1 ทุก Wave ใช้ 15 เหรียญอัญเชิญ
- [x] อัศวิน/ผู้กล้าเหวี่ยงดาบ + รอยฟัน, นักปรุงยาเหวี่ยงแขนขว้างขวด
- [x] เสียงโจมตีทุกยูนิต + เสียงทักษะ/ปราสาท/คัตซีน (สังเคราะห์ขึ้นใหม่ `td/audio/sfx_*.wav`)
- [x] ตอนแพ้มีคัตซีนปราสาทระเบิดพังทลาย, ตั้งค่าความเร็วกล้อง/ความไวเมาส์ (เมนูตั้งค่า + เมนูหยุดเกม)
- [x] บอสกลับมาความเร็ว 0.4 (ผู้กล้าตัดเลือดได้ราวครึ่งหลอดตอนบินผ่าน) + เสียงไซเรนดังจากประตูก่อนบอสโผล่
- [x] บันทึกหน่วยสอดแนม: ศัตรูใช้ชื่อแบบที่อาณาจักรเรียก ปลดล็อกบันทึกเมื่อพบครั้งแรก
- [x] ตอนชนะประตูมิติระเบิดและหายไป, ผู้กล้าเรียกกลับแล้วต้องรอ 10 วิ คูลดาวน์ทักษะนับต่อ

## ควรทำต่อ (เรียงตามความสำคัญ)
1. **อัปโหลด web build ใหม่ขึ้น itch.io** (`build/haupttuer_web.zip`)
2. **อัปเดตสไลด์ Canva**: รายชื่อยูนิตใหม่ + ทักษะ, หน้าเนื้อเรื่อง/คัตซีน, เมนูหลักใหม่
3. ลบไฟล์เก่าที่ไม่ใช้แล้วในเครื่อง: `td/characters/`, `td/models/{ranger,knight_r,sorceress,gate_soldier,crystal,treant,wizard,ballista,catapult}.tscn`, `td/data/defenders/{crystal,treant,wizard,ballista,catapult}.tres`, `td/icons/menu_bg.png`
4. ภาพเหมือนตัวละคร (portrait) ข้างกล่องข้อความคัตซีน

## ไอเดียทำให้เกม "ขายได้" (ยังไม่ได้ทำ)
- **หลายด่าน + แผนที่โลก**: ด่านที่ 2-5 ธีมต่างกัน (หิมะ/ทะเลทราย/ในเมือง) ปลดล็อกทีละด่าน ให้ดาว 1-3 ดวงตามชีวิตที่เหลือ
- **ต้นไม้พัฒนาถาวร (Meta progression)**: ใช้ดาวที่ได้ปลดล็อกความสามารถถาวร เช่น ทองเริ่มต้น +50, คูลดาวน์ทักษะ -10%
- **ผู้กล้าหลายคนให้เลือก** ก่อนเข้าด่าน (สายเวท / สายดาบ / สายธนู) แต่ละคนมีทักษะต่างกัน
- **ศัตรูพิเศษ**: หน่วยซ่อมรถ, โดรนบินฝูง, ทหารใส่โล่, รถหุ้มเกราะปล่อยทหาร
- **ความสำเร็จ (Achievements)** + ลีดเดอร์บอร์ดออนไลน์ของโหมดไม่สิ้นสุด
- **ภาษาอังกฤษ** (Godot มีระบบแปลภาษาในตัว) เพื่อขายบน Steam / itch.io ได้กว้างขึ้น
- **ระดับความยาก** ง่าย/ปกติ/ยาก และโหมด "ท้าทายรายวัน" ใช้ seed เดียวกันทุกคน
- ทำ **Trailer 30-60 วินาที** จากคัตซีนอัญเชิญผู้กล้า + ฉากบอส สำหรับหน้าร้าน
